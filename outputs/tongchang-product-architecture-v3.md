# 同场 App 信息架构 v3：发现 / 圈子 / 我的

## 1. 底部导航最终定义

```text
发现                 圈子                 我的
活动发现             兴趣社交             个人中心
```

原来的 “Dazzle” 统一改名为 **圈子**。

### 发现

只负责发现活动和进入活动匹配流程：

- 演唱会
- 展览
- Livehouse
- 更多
- 搜索活动
- 热门活动轮播推荐
- 活动列表
- 活动详情
- 找搭子流程

### 圈子

负责完整的社交内容：

- 推荐
- 关注
- 关注的人
- 话题
- 活动体验分享
- 搭子回顾
- 找搭子帖子
- 点赞、评论、收藏、分享
- 关注用户
- 匿名评价和标签

### 我的

负责个人资料和记录：

- 编辑主页
- 我的帖子
- 我的收藏
- 我的活动
- 我的搭子
- 评价和标签
- 匹配偏好
- 设置

## 2. 发现页最终结构

```text
发现
├── 顶部状态栏
├── 顶部操作栏
│   ├── 同场 Logo
│   ├── 搜索入口
│   ├── 消息入口
│   └── 三横线菜单
├── 搜索栏
├── 活动分类
│   ├── 演唱会
│   ├── 展览
│   ├── Livehouse
│   └── 更多
├── 热门活动轮播推荐
├── 今天，去哪里？
├── 推荐活动列表
└── 底部导航：发现 / 圈子 / 我的
```

### 2.1 搜索栏

搜索栏位于顶部状态栏下方，支持搜索：

- 演唱会名称
- 展览名称
- Livehouse 名称
- 歌手或乐队
- 场馆
- 城市
- 活动话题

点击搜索栏进入搜索页：

```text
搜索页
├── 输入框
├── 搜索历史
├── 热门搜索
├── 活动结果
├── 帖子结果
├── 用户结果
└── 话题结果
```

搜索结果点击后进入对应详情。

### 2.2 活动分类

首页只展示图片中已有的三个主要分类，并增加一个“更多”：

```text
演唱会    展览    Livehouse    更多
```

点击后行为：

- **演唱会**：显示演唱会活动流。
- **展览**：显示展览活动流。
- **Livehouse**：显示 Livehouse 活动流。
- **更多**：打开分类面板，可选择音乐节、话剧、脱口秀、艺术市集、电影放映等。

这里的分类变化只影响活动发现内容，不切换到圈子内容。

### 2.3 热门活动轮播推荐

原来活动主图的位置改为横向轮播卡片，自动播放最近热门活动。

每张卡片包含：

- 活动图片
- 活动类型
- 活动名称
- 时间和地点
- 当前参与人数
- 正在找搭子人数
- 立即查看按钮

轮播逻辑：

- 每 4 秒自动切换。
- 支持左右滑动。
- 底部显示分页圆点。
- 用户手动滑动后暂停自动播放 5 秒。
- 点击卡片进入具体活动详情。
- 轮播内容根据活动热度和用户城市更新。

### 2.4 “今天，去哪里？”活动列表

轮播下面保留图片中的标题和活动卡片，但改为可滚动活动列表：

- 推荐活动
- 距离较近的活动
- 即将开始的活动
- 正在找搭子的活动

点击活动卡片进入活动详情，点击头像进入用户主页，点击“找同好”进入该活动的匹配流程。

## 3. 右上角三横线菜单

三横线不是装饰按钮，点击后打开侧边菜单或半屏菜单：

```text
菜单
├── 消息
├── 活动提醒
├── 我的收藏
├── 浏览历史
├── 夜间模式
├── 护眼模式
├── 字体大小
├── 个性化推荐
├── 隐私设置
├── 通知设置
├── 帮助与反馈
└── 关于同场
```

### 菜单功能

- **消息**：进入聊天、评论、点赞、关注和系统通知。
- **活动提醒**：查看即将开始的活动和集合提醒。
- **我的收藏**：查看收藏的活动、帖子和用户。
- **浏览历史**：查看最近浏览的活动和帖子。
- **夜间模式**：跟随系统 / 白天 / 夜间。
- **护眼模式**：降低高亮颜色、调整背景色温和对比度。
- **字体大小**：标准 / 大 / 特大。
- **个性化推荐**：选择音乐、展览、摄影等兴趣，设置城市和推荐范围。
- **隐私设置**：控制个人主页、活动记录、评价标签是否公开。
- **通知设置**：控制聊天、活动、点赞、评论等通知。

设置修改后立即影响整个 App 的显示和推荐行为。

## 4. 圈子页最终结构

```text
圈子
├── 顶部标题和搜索
├── 推荐 / 关注 / 关注的人 / 话题
├── 信息流
│   ├── 活动体验帖子
│   ├── 搭子回顾帖子
│   ├── 找搭子帖子
│   ├── 活动评价帖子
│   └── 话题讨论帖子
├── 发布按钮
└── 底部导航：发现 / 圈子 / 我的
```

圈子页不显示“找到 3 位同场搭子”结果列表。

### 圈子信息流交互

- 点赞：即时更新数量和状态。
- 评论：进入评论页，支持回复和@用户。
- 收藏：保存到我的收藏。
- 分享：复制链接或系统分享。
- 关注：关注作者并更新关注流。
- 活动标签：进入活动详情。
- 话题标签：进入话题页。
- 用户头像：进入用户主页。
- 更多按钮：不感兴趣、举报、拉黑。
- 发布按钮：进入发布内容页。

## 5. 我的页和全局设置

```text
我的
├── 头像 / 昵称 / 个性签名
├── 编辑主页
├── 我的帖子
├── 我的收藏
├── 我的活动
│   ├── 计划参加
│   ├── 进行中
│   ├── 已完成
│   └── 已取消
├── 我的搭子
│   ├── 最近聊天
│   ├── 历史搭子
│   └── 共同活动次数
├── 我的评价和标签
├── 匹配偏好

```

主页编辑支持：

- 更换头像
- 修改昵称
- 修改个性签名
- 修改城市
- 修改主页背景
- 添加或删除兴趣标签
- 设置内容可见范围

## 6. 活动匹配流程仍保持独立

```text
发现 → 活动详情 → 找同好 → 需求设置 → 匹配中 → 匹配结果
                                                  ↓
                                     小满 / 阿树 / Yuki 详情
                                                  ↓
                                               聊天
```

“匹配结果”只属于具体活动流程，不出现在圈子导航首页。
